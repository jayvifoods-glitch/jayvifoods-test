# Jayvi Foods v22.0 — consolidated build

This is the consolidated pre-production build.

## Upload
Upload the contents of this folder to the test/production site as a single set. Do not upload any of the old v15/v17/v18/v19/v20/v21 patch files.

### Core files
- index.html — storefront
- app.js — all storefront logic + mobile/cart/checkout fixes
- style.css — all storefront styles
- admin.html — admin portal
- admin.js — all admin logic
- admin.css — all admin styles
- admin-login.html — admin login (self-contained)
- help.html — help/support page
- images/ — site assets and product gallery assets

## Version
Website version: **v22.0**

## Important
This is still a browser/localStorage prototype for admin/order data. Before public production use, backend authentication, order persistence, payment verification and database storage must be secured server-side.
